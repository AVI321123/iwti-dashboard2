IWTI V3 • חבילה חינמית ללא Token
================================
1. חלץ את כל הקבצים לאותה תיקייה.
2. התקן Python 3.9 ומעלה אם צריך.
3. הפעל START_IWTI.bat.
4. פתח http://127.0.0.1:8765/iwti_dashboard.html

API: /api/cyber (SANS DShield) /api/aviation (Google News RSS).
רענון תצוגה כל 60 שניות; איסוף מקורות כל 60 דקות לכל היותר.
אין דרישה למפתח API או ספריות צד שלישי.
מערכת מקומית בלבד. נדרש חיבור אינטרנט בעת עדכון מקורות.
מדדי מלחמה בדשבורד הם נתוני הדגמה ולא הסתברות אמיתית.
מדד התעופה: כמות פרסומים ציבוריים על שיבושי תעופה אזרחית, לא מטוסי קרב.
אין זיהוי מטוסים, מסלולים בזמן אמת או ייחוס מתקפות למדינות.
GitHub references: github.com/openskynetwork/opensky-api; github.com/JeanExtreme002/FlightRadarAPI
