תהליך חיזוי מומלץ

איסוף נתונים עם חותמות זמן → זיהוי כפילויות ותעמולה → אימות רב־מקורי → תיוג אירועים היסטוריים → אימון לפי חלונות זמן → Backtesting וכיול הסתברויות. אין להפיק אחוזי מלחמה מדומים מנתוני סייבר או מידע לא מאומת.

מתאם בין פעילות סייבר להסלמה אינו מוכיח שמתקפה צבאית עומדת להתרחש.

Cyber Telemetry API

ברירת המחדל היא בקשה ל־/api/cyber משרת IWTI המצורף. אפשר להזין כתובת Endpoint שמחזירה JSON בפורמט המערכת. אין להדביק Token סודי בדפדפן; שמרו אותו בשרת בלבד.

לא מחובר. הדף ינסה להתחבר לשרת באופן אוטומטי בעת פתיחה.
